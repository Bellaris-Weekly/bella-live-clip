# 贝报切片助手（bella-live-clip）

当前版本为 `2.11.17`。B 站投稿视频与直播片段剪辑、下载油猴脚本。

本版优化直播预览：修复定位到部分位置后反复下载、一直不出画面的问题；视频分片和预览图直连 B 站 CDN；拖动时先显示 B 站预览图，停下或松开后再定位视频；打开录像先显示封面或关键帧，不再黑屏等待；更新检查只读取脚本开头。

支持普通投稿视频，以及贝拉、乃琳、嘉然、心宜、思诺的本场直播回看与近 14 天历史回放。

## 安装

1. 安装 Tampermonkey。
2. 点击 [立即安装](https://share.bellaris.fans/bella-live-clip.user.js)，使用发布构建。
3. 在同一个浏览器登录 B 站，刷新 B 站页面，点击右下角剪辑图标。

默认快捷键为 **Alt＋Shift＋C**。点击入口或使用快捷键均可收起面板。

## 使用

- **直播截图：** 播放器右上角相机可立即下载当前帧，保存为视频原尺寸的无损 PNG，不含网页弹幕和控件。需要原画时请提前选择原画画质；文件名仅含主播名和时间。支持活动页内嵌播放器；与贝报 GIF 助手同时安装时由先启动的插件负责截图，不重复下载。

- **预览截图：** 切片界面的预览窗右上角提供同款相机，鼠标移入预览窗显示、移出隐藏，悬停提示仅为“截图”。录像与投稿预览都保存当前视频原尺寸的 PNG；投稿直接读取对应网页视频，不放大预览缩略图。文件名沿用主播名或 UP 主名加时间。

- **版本与更新：** 标题旁显示当前运行版本。每次打开面板时都静默读取脚本开头的版本信息，不下载完整脚本，也不单独维护版本文件，无 24 小时限制（正在检查时复用同一次请求）；平时点击版本号可手动检查，检查中显示小动效，结果通过悬停提示查看。有新版时版本号显示红点和细红框，点击进入油猴安装确认；安装完成后刷新 B 站页面生效。检查失败不影响剪辑，不弹窗、不自动安装或降级。

- **普通投稿页打开：** 自动载入当前视频、当前分 P，显示标题、UP 主、分 P 名称和导出清晰度。小画面镜像网页播放器，打开或关闭面板不暂停、不跳转，声音只由 B 站播放；默认选中当前分 P 的完整范围。沿用时间轴、“设为开始／设为结束”和方向键操作，再点击“导出”并选择 MP4 保存位置。
- **投稿画质与声音：** 自动选择账号可获取的最高兼容 H.264 画质和 AAC 音轨，不固定降到某个分辨率；未登录或权限不足时，以接口实际提供的画质为准。分离的声音和画面在浏览器内合并成 MP4，音轨读取失败会报错，不会静默保存为无声视频。
- **投稿导出：** 固定使用精确裁剪，不显示“原画 / 精确”选择，直接按所选起止点导出。切点受视频帧和音频采样粒度影响。文件名包含视频标题、分 P 和所选时间。投稿页不显示直播专用的“整场”开关；保持全选即可导出完整的当前分 P。
- **投稿导出进度与大小：** 准备时显示“正在定位选段”，开始剪辑后显示处理百分比，MP4 封装完成才到 100%。有分段索引时直接定位选段附近的数据，避免从视频开头扫描到选区。上方“预计成品约”在读取索引后按选区附近的实际分段大小更新；头尾重编码和封装会带来误差。下方“已读取”是累计网络读取量，包含索引、关键帧和预读，不是成品大小；保存完成后显示最终文件大小。
- **切换视频：** 面板打开且空闲时，网页换视频或分 P 会自动更新剪辑对象。导出期间切换页面不会改变正在导出的内容，完成后可点“剪辑当前视频”载入新对象。关闭再打开时重新检查视频身份。点击“选择直播”仍可使用原有直播功能，列表上方可返回当前投稿。
- **投稿按需读取：** 镜像预览不额外下载或解码视频；操作时间轴后才按需读取低画质缩略图，导出只读取选中片段所需的媒体字节范围，使用有限缓存。短暂断网重试当前读取，可随时停止。导出先选择保存位置，分块写入 MP4；不在内存中保存完整成品。投稿读取不使用直播的分片清单。

- **直播间内打开：** 按房间号优先通过房间基础信息接口查询当前场次，直接剪已生成的录像，不依赖周年庆等活动页的模板。接口不可用或场次数据不完整时尝试标准网页数据，并校验房间号和场次信息。未开播或两个来源均不可用时，可重新检查或进入历史场次。没有数字房间号的独立活动链接仍需从成员列表选择主播，不自动猜测多个直播间中的目标。
- **其他 B 站页面打开：** 顶部选择贝拉、嘉然、乃琳、心宜、思诺，下方通过紧凑信息卡片浏览各场回放，保留原标题、北京时间和实际场次时长。点卡片进入独立剪辑页，返回保留成员与列表位置。场次数据到达后即可选择，不等待日程和头像；补充信息在后台更新。
- **直播预览加载：** 直接从所选录像段和预览时间开始加载，避免先加载首段再跳转；打开时先显示直播间封面或所在位置的 B 站关键帧，首帧解码后切换为视频。分片和预览图从页面直连 B 站 CDN，直连失败时自动改走油猴通道。大小预估和按需截帧在首帧后才开始，减少首屏竞争。
- **时间轴预览图：** 直播在后台按 60 秒间隔索引 B 站关键帧图片（与 B 站剪辑页相同的间隔），投稿使用 B 站进度预览图并在载入时预热。某位置没有图片时使用相邻图片；只有接口无权限或超时才按需截帧，最多同时处理两张。图片在当前场次内有限缓存，缩放和直播增长时复用，换场释放。
- **剪辑页只有一个播放器和一条时间轴。** 按住时间轴预览对应位置，拖动左、右边界时分别预览起点和终点。直播拖动中显示最接近的 B 站预览图（约每分钟一张），鼠标停下或松开后定位到精确画面；无预览图时降低频率直接定位视频。为避开分片边界，定位点可能后移不到 0.1 秒。
- **键盘微调：** 左／右方向键每次后退／前进 5 秒。点击时间轴起点、终点，或点击“设为开始／设为结束”后，方向键调整对应边界；点击画面或时间轴空白处后恢复调整播放进度。缩放时间轴、长按方向键和按住 Shift 均保持 5 秒步进，到达录像边缘或另一端点时停止，不允许起止点交叉。
- **松开边界，时间轴自动适配当前完整选区。** 初次打开默认选中完整视频起止；拖动后两侧保留约 6% 余量。滚轮缩放、Shift＋滚轮平移只改变显示范围，不改变实际选区。
- **画面操作：** 单击画面播放／暂停，双击进入全屏。投稿镜像始终控制 B 站播放器，声音和倍速沿用 B 站设置；直播回放全屏使用浏览器原有控制栏。
- **投稿播放控制：** 插件与 B 站共用进度，普通播放不受剪辑选区限制。“设为开始／设为结束”只标记位置；拖动任意一条进度条时，小画面临时显示 B 站进度预览图，松开后定位并恢复画面同步。插件拖动不会暂停原视频；拖动 B 站进度条遵循原播放器行为。预览图为抽样画面，不影响精确导出。点击“播放选段”才从起点播放并在终点停止。导出不会暂停 B 站视频。
- **直播回放播放控制：** 视频下方左侧并排“设为开始／设为结束”，中间为播放／暂停图标，右侧显示“当前时间 / 总时长”。播放限定在当前选区内，到结束点自动暂停、不循环；在选区外点击播放或播完后再次播放，会从起点开始。拖动后仅在选区内恢复之前的播放状态，到达或超过终点则停在终点。暂停时仍可预览选区外画面，方便重新选点。
- 直播回放调整完后点击“导出”，先选择保存位置和文件名。后台读取清单，下载选区及解码所需的边界分片；关键帧组跨多个分片时，会继续向前后查找。无需再载入第二个播放器。
- 直播回放的导出区域左侧通过“原画 / 精确”切换模式，右侧仅显示预估大小；顶部场次信息显示匹配到的直播类型。原画不重新编码；精确裁剪保留原始分辨率与帧时间，使用接近原视频码率的 H.264 编码，优先使用可用的硬件编码器。实际码率会随画面复杂度和短片关键帧开销浮动，重新编码的部分仍有二次压缩损失。切点受视频帧和音频采样粒度影响。选区限定在当前段内，每次导出一个文件。
- **精确模式的拼接条件：** 按可独立解码的关键帧组处理头尾，不按服务器下载分片硬切。原片和浏览器编码器使用独立的 H.264 参数编号，同一个 MP4 保存两套参数，因此参数集不同也能复制中间画面并拼接；AAC 音频同时保留原包。已用 Chrome 的真实直播回放验证首尾编码、中间数据不变及完整播放。选区短于独立关键帧组时仍需编码全部选中画面；遇到空的头尾画面区间、不支持的规格或无法独立切分的画面引用时，会明确提示并按原码率整段编码。
- **选区时间线与磁盘保存：** 选区和整场共用实际音视频时间戳处理，保留 B 帧顺序和音画偏移，不再按累计清单时长强行拼接。选区最多同时下载 2 个分片，边下载边无损整理为浏览器临时文件，再从该文件裁剪并直接写入目标文件；每个断流段处理完即释放临时文件。进度区显示整理、裁剪和保存阶段，最终文件关闭成功才到 100%。正常取消或失败会停止请求、清理临时文件和当前未完成的成品。
- **空间与浏览器要求：** 导出需要 Chrome / Edge 的文件保存接口；直播选区还需要浏览器临时存储。临时存储位于浏览器所在磁盘，即使成品保存到其他磁盘，也需要为当前选段的原画中间文件留出空间。浏览器配额不足会明确报错，不回退为整份文件驻留内存；文件索引仍随时长增长，单个源分片也需要暂存。刷新、强制关闭页面或浏览器崩溃不能续传，且可能留下未及清理的临时数据。
- 精确模式保留原有 AAC 音频及时间位置，整段视频回退编码也不重压音频；非 AAC 音轨会明确报错，仍可尝试原画模式。

- **时间轴摘要：** 框内右上角显示片段时长，下方居中显示紧凑起止时间，右侧显示当前缩放倍率。导出区域只显示大小，不再标注精确模式的原画参考。
- **下载整场：** 勾选时间轴框左下角的“整场”，再点击下方“导出整场”，立即选择 MP4 保存位置，按原画逐段重封装并写入文件，无需把整场录像保存在内存。需要 Chrome 的文件保存接口；下载的是当前已加载的录像范围，直播中可刷新后再下载。断流空档不占输出时长，不能完整封装的编码会报错。
- 整场导出依据分片的实际音视频时间戳拼接，保留 B 帧解码顺序，处理清单时长偏差及跨分片时间重置。音视频统一调整时间，不重新编码；输出常规 MP4，避免分段 MP4 在部分播放器中的 B 帧音画偏移。
- 检查实际音视频包，纠正容器的关键帧误标。开头或断流后缺少参考画面时，从首个可独立解码的关键帧开始保留视频，音频保持原时间位置；普通连续分片的依赖帧照常保留。
- **停止整场导出：** 点击“停止”后终止网络请求，完成正在写入的分片并保存 MP4 索引。已完成部分保存在原先选择的位置，可正常播放，界面显示实际保存时长和大小。停止后需等保存完成再关闭页面；尚未写入的预读分片不计入文件。片段导出的停止仍直接中止当前任务。
- **并行下载：** 整场最多同时下载 6 个分片，使用 64 MiB 的预读预算，处理后释放媒体数据。未知大小的在途分片可能短时超过预算；单个大分片仍需暂存。视频边下边写盘，完成时写入 MP4 索引，索引内存随录像时长增长。界面显示近期已完成分片的平均接收速度；实际速度受视频服务器、代理线路和本机处理速度影响。
- **自动重连：** 整场和选区导出遇到断网、连接中断、超时或 HTTP 408/429/5xx 时，保留已完成的下载与处理进度，按 1、2、4、8 秒后最高每 10 秒重试失败分片，直到恢复或手动取消。代理切换后无需从头导出；尚未完整收到的分片会重新下载。页面必须保持打开，刷新或关闭后不能续传。
- 重连期间显示提示和重试次数，取消会停止请求与等待。链接过期、权限错误、媒体损坏或写盘失败仍会停止并中止文件写入，避免将半成品当作成功结果。

进入投稿页以外的其他 B 站页面后，脚本会在后台预加载当前选中成员的近 14 天场次，同时检查该成员是否正在直播：正在进行的场次会显示在对应列表首位并标注“直播中”，首次加载其他成员或刷新列表也会检查。列表会同步日程和参与人头像；打开面板时直接复用这份数据。预览按需缓冲。最新直播录像有生成延迟；打开正在直播的场次后，每 30 秒检查已生成的录像，自动延长可用时间轴，也可点击刷新图标（悬停提示“刷新录像”）手动更新。自动增长保留播放位置、已选片段和缩放视野；显示整段时视野随录像延长，勾选“整场”时选区同步延长。断流后新增分段按钮，不自动切换当前段。拖动时间轴、导出、页面在后台或面板关闭时暂停自动更新，失败后保留已有录像并重试。时间从开播计算，开播准备或断流间隙可能没有可预览内容。选区和整场均直接写盘；完整保存当前已加载录像可勾选“整场”，省去选区裁剪的临时文件和额外本地读写。取消勾选会恢复原来的选区。

贝拉、嘉然、乃琳的场次会按录像所属月份读取 [直播日程](https://calendar.bk0717.us.ci/calendar-2026-06.ics)，匹配直播间与开播时间后显示类型标签及参与成员的小头像，头像旁不显示姓名。日程仅用于补充信息，不替换原标题和实际时长；未匹配时不猜测类型或成员，日程不可用也能正常选择录像。点击刷新场次可同时更新日程。

## 权限与边界

- 使用当前浏览器登录态，是否可回放取决于账号和主播权限。
- 历史场次来自平台近 14 天回放接口，不是永久录像仓库。
- 登录态请求仅发往 B 站直播 API 和投稿 API；视频服务器、日程、头像资料及更新检查为匿名请求。投稿接口通过网页自身的登录会话请求；预览直接显示 B 站正在播放的画面，缩略图使用最低可用 H.264 画质，精确导出使用最高可用 H.264 画质与 AAC 音轨。投稿媒体优先从接口给出的常规 CDN 地址读取，不扩大到任意域名权限。
- 投稿功能支持 BV/av 普通视频及当前分 P，不包括番剧、电影、本地文件、字幕或弹幕烧录、多段拼接和批量分 P 下载；不绕过账号访问权限。
- 不发布内容、不创建投稿草稿；脚本不保存 Cookie、签名媒体链接或视频到扩展存储。
- 接口并非承诺稳定的公开 API，平台改版后可能需要更新。

## 日志服务（维护者）

仓库包含可供多个项目使用的 Cloudflare Worker + D1 日志服务，支持匿名写入、按来源去重和通过 Cloudflare 控制台查询。发布方式见 [日志服务说明](server/logs/README.md)。

构建和发布只生成、上传压缩的 `bella-live-clip.user.js`，检查更新和安装使用同一地址。

生产部署只读取 GitHub Actions Secret `LOG_SERVICE_CONFIG`，不在仓库中保存实际账户、Worker、数据库、域名或令牌配置。资源及域名绑定由维护者预先完成；部署流程只检查并更新已有 Worker 和数据库，不读取、验证或修改域名，也不自动创建替代资源。发布构建从同一个 Secret 注入公开接收地址和对应网络权限，仓库中的构建不含实际地址；管理凭据不会进入插件。

预览截图浏览器验证：运行 `npm run serve`，打开 `http://127.0.0.1:8765/?screenshot`，选择场次后移入预览并点击相机，再移出预览。测试页应显示 `hoverShown`、`leaveHidden`、`png` 和 `nativeSize` 均为 `true`，并实际下载原尺寸 PNG。
