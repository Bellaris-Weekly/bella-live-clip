# 贝报切片助手（bella-live-clip）

当前版本为 `2.3.0`。B 站直播片段剪辑与下载油猴脚本。

可安装的油猴脚本，支持贝拉、乃琳、嘉然、心宜、思诺的本场直播回看与近 14 天历史回放。

## 安装

1. 安装 Tampermonkey。
2. 打开 [GitHub 安装文件](https://raw.githubusercontent.com/Bellaris-Weekly/bella-live-clip/main/bella-live-clip.user.js)，或点击 [立即安装](https://share.bellaris.fans/bella-live-clip.user.js)。
3. 在同一个浏览器登录 B 站，刷新 B 站页面，点击右下角剪辑图标。

默认快捷键为 **Alt＋Shift＋C**。点击入口或使用快捷键均可收起面板。

## 使用

- **直播间内打开：** 直接剪当前场次已生成的录像。未开播或接口不可用时，可重新检查或进入历史场次。
- **其他 B 站页面打开：** 顶部选择贝拉、嘉然、乃琳、心宜、思诺，下方通过紧凑信息卡片浏览各场回放，保留原标题、北京时间和实际场次时长。点卡片进入独立剪辑页，返回保留成员与列表位置。
- **剪辑页只有一个播放器和一条时间轴。** 按住时间轴预览对应位置，移动鼠标持续更新；拖动左、右边界时分别预览起点和终点。
- **松开边界，时间轴自动适配当前完整选区。** 初次打开默认选中整场起止；拖动后两侧保留约 6% 余量。滚轮缩放、Shift＋滚轮平移只改变显示范围，不改变实际选区。
- **画面操作：** 非全屏隐藏内置控制栏，单击画面播放／暂停，双击进入全屏；全屏使用浏览器原有控制栏，退出后重新隐藏。
- **播放控制：** 视频下方左侧并排“设为开始／设为结束”，中间为播放／暂停图标，右侧显示“当前时间 / 总时长”。拖动播放位置或选区边界后恢复拖动前的播放状态。
- 调整完后直接点击“导出”，后台读取整场清单，只获取相交的视频分片并裁剪。无需再载入第二个播放器。
- 导出区域左侧通过“原画 / 精确”切换模式，右侧显示时长和大小；顶部场次信息显示匹配到的直播类型。原画不重新编码；精确裁剪使用浏览器编码。切点受视频帧和音频采样粒度影响。跨断流会生成多个文件，分别点击保存。

- **导出摘要：** 时长和大小在右侧以同等文字样式显示为“1时2分3.4秒 · 约 62.4 MB”，省略“选中”和“预估”前缀；时间轴下方居中显示紧凑起止时间。预估大小按各段原画码率采样计算，精确重编码模式仅提供原画参考值。
- **下载整场：** 勾选时间轴框右下角的“整场”，再点击下方“导出整场”，立即选择 MP4 保存位置，按原画逐段重封装并写入文件，无需把整场录像保存在内存。需要 Chrome 的文件保存接口；下载的是当前已加载的录像范围，直播中可刷新后再下载。断流空档不占输出时长，不能完整封装的编码会报错。
- 整场下载使用共享 32 MiB 分片缓存和分段 MP4 写盘；单个服务端分片超过缓存预算时仍需暂存该分片。取消、网络失败或写盘失败会中止文件写入，避免把半成品当作成功结果。

进入其他 B 站页面后，脚本会在后台预加载当前选中成员的近 14 天场次，并同步日程和参与人头像；打开面板时直接复用这份数据。预览按需缓冲。最新直播录像有生成延迟，点击“刷新录像”更新范围。时间从开播计算，开播准备或断流间隙可能没有可预览内容。选区下载会占用与选区长度相关的内存；保存整场请勾选“整场”后下载。取消勾选会恢复原来的选区。

贝拉、嘉然、乃琳的场次会按录像所属月份读取 [直播日程](https://calendar.bk0717.us.ci/calendar-2026-06.ics)，匹配直播间与开播时间后显示类型标签及参与成员的小头像，头像旁不显示姓名。日程仅用于补充信息，不替换原标题和实际时长；未匹配时不猜测类型或成员，日程不可用也能正常选择录像。点击刷新场次可同时更新日程。

## 权限与边界

- 使用当前浏览器登录态，是否可回放取决于账号和主播权限。
- 历史场次来自平台近 14 天回放接口，不是永久录像仓库。
- 登录态请求仅发往 B 站直播接口；视频服务器、日程及头像资料请求为匿名请求。
- 不发布内容、不创建投稿草稿；脚本不保存 Cookie、签名媒体链接或视频到扩展存储。
- 接口并非承诺稳定的公开 API，平台改版后可能需要更新。
